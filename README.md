# Seunghyun Ham — Portfolio

Static portfolio site configured for GitHub Pages.

## Publish

1. Create a new GitHub repository, for example `Hamsss/portfolio`.
2. Push this folder's `main` branch to that repository.
3. In **Settings → Pages**, set **Build and deployment** to **GitHub Actions**.

The included workflow deploys automatically after every push to `main`. It supports both a project page (`https://hamsss.github.io/portfolio/`) and a user page (`https://hamsss.github.io/`).
